# ARCHITECTURE
- proxy_rotator.py - Core rotation logic
- proxy_checker.py - Proxy validation system
- system_proxy.py - Windows system proxy control
- gui_app.py - PyQt5 interface
- main.py - Application entry point

# FEATURES:
- ✅ Multi-architecture Design - Separate classes for each functionality
- ✅ Advanced GUI - PyQt5 with dark theme and real-time updates
- ✅ Proxy Validation - Concurrent checking with detailed metrics
- ✅ System Integration - Windows registry manipulation for system-wide proxy
- ✅ Rotation Control - Configurable intervals with background threading
- ✅ CLI & GUI Modes - Flexible operation modes
- ✅ Error Handling - Comprehensive exception management
- ✅ Logging System - Detailed activity tracking

## HOW TO USE:
- pip install -r requirements.txt
- python main.py --gui
